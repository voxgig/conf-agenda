# `<conf-agenda>`

The embeddable agenda component (SPEC §11). Read-only, framework-free, under 30KB gzipped.

```html
<script type="module" src="https://conf-agenda.voxgig.com/embed/v1.js"></script>
<conf-agenda org="nearform" conference="nodeconf-eu-2027" view="grid"></conf-agenda>
```

## Attributes

| Attribute | Values | Default | Meaning |
|---|---|---|---|
| `org` | slug | required* | Organisation |
| `conference` | slug | required* | Conference |
| `view` | `grid` · `list` | `grid` | Layout |
| `track` | id | all | Restrict to one track |
| `theme` | `auto` · `light` · `dark` | `auto` | `auto` follows `prefers-color-scheme` |
| `src` | URL | hosted | Data source — a self-hosted backend or a static `agenda.json` |
| `key` | string | none | Embed key, for previewing an unpublished agenda |
| `lang` | BCP-47 | `en` | Date locale |
| `debug` / `mark` | | | Diagnostics, instance marker |

\* unless `src` is given.

## Styling

**Tokens** are the normal path — they pierce shadow DOM, so no forking:

```css
conf-agenda { --ca-primary: #e70042; --ca-bg: transparent; --ca-font: 'Inter', sans-serif; }
```

**`::part()`** for what tokens cannot express: `grid`, `caption`, `room-header`, `time-label`,
`session`, `session-title`, `cancelled-badge`, `error`, `empty`, `list`. The part set is an API —
adding is fine, renaming is breaking. Internal class names are **not** an API.

## Events

`conf-agenda:ready` · `conf-agenda:select` · `conf-agenda:error` — composed custom events, each
carrying the instance `mark`.

## Constraints this component holds to

- **Read-only.** It displays; it never writes. No auth, no cookies, no storage.
- **One network request** on load.
- **No analytics, ever.** It runs on someone else's site and their visitors did not agree to us.
- **A real `<table>`** — rooms are column headers, times are row headers, so a screen reader
  announces "Room A, 10:00" with no ARIA bolted on. Colour is never the sole carrier of meaning.
- **Degrades honestly.** A plain message; never an empty box, never a stack trace.
- **No speaker emails.** They are not in `agenda.json` to begin with (C6).

## Develop

```sh
npm install
npm run build       # vite lib build -> dist/conf-agenda.mjs + .umd.cjs
npm run size        # enforce the 30KB gzipped budget
npm test            # build + size + Playwright against test/index.html
node tool/screenshot.mjs
```

`test/index.html` stands in for an organiser's own site — it sets deliberately hostile global CSS
(`table { border: 6px dashed red !important }`) so a style leak would be visible.
`test/agenda.json` is generated by `backend/tool/make-fixture-agenda.mjs` through the real publish
pipeline, so the page renders what the backend actually produces.
